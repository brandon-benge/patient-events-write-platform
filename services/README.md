# Services Module

This directory contains the Java Spring Boot API for patient admission (write path), idempotency, PHI persistence, and validation read endpoints.

## Contents

- [pom.xml](pom.xml) — Maven build config and dependencies.
- [docs/](docs/) — service-scoped docs (if present).
- [src/](src/) — application source and tests.
- [target/](target/) — build output (generated by Maven).

---

## What This Service Does

The service implements:

1. **Write admission APIs** (`POST`/`PUT`) with idempotency semantics.
2. **PHI commit flow** with versioned rows in Postgres.
3. **Redis-backed receipt tracking** (`ADMITTED`, `PHI_COMMITTED`, `PHI_REJECTED`, `PHI_FAILED`).
4. **Read APIs** for de-identified and PHI validation queries.

Core wiring starts in [`com.patienteventswriteplatform.patient.PatientServiceApplication`](src/main/java/com/patienteventswriteplatform/patient/PatientServiceApplication.java).

## Source Layout

## `src/main/java/com/patienteventswriteplatform/patient`

### `api/` (HTTP DTOs + Controllers)

- [`PatientWriteController`](src/main/java/com/patienteventswriteplatform/patient/api/PatientWriteController.java)  
  - `POST /api/v1/patient`
  - `PUT /api/v1/patient/{phi_id}`
  - Delegates to [`com.patienteventswriteplatform.patient.service.AdmissionService`](src/main/java/com/patienteventswriteplatform/patient/service/AdmissionService.java).
- [`PatientReadController`](src/main/java/com/patienteventswriteplatform/patient/api/PatientReadController.java)  
  - `GET /api/v1/deid/patients/by-deid/{de_id}`
  - `GET /api/v1/deid/patients/by-phi_id/{phi_id}`
  - `GET /api/v1/phi/patients/by-deid/{de_id}?version=<v|latest>`
  - `GET /api/v1/phi/patients/by-phi_id/{phi_id}`
  - Delegates to [`com.patienteventswriteplatform.patient.service.ReadService`](src/main/java/com/patienteventswriteplatform/patient/service/ReadService.java).
- Response DTOs:
  - [`AdmissionResponse`](src/main/java/com/patienteventswriteplatform/patient/api/AdmissionResponse.java)
  - [`DeidReadResponse`](src/main/java/com/patienteventswriteplatform/patient/api/DeidReadResponse.java)
  - [`PhiReadResponse`](src/main/java/com/patienteventswriteplatform/patient/api/PhiReadResponse.java)
- Request DTO:
  - [`WritePatientRequest`](src/main/java/com/patienteventswriteplatform/patient/api/WritePatientRequest.java)

### `service/` (Business logic)

- [`com.patienteventswriteplatform.patient.service.AdmissionService`](src/main/java/com/patienteventswriteplatform/patient/service/AdmissionService.java)  
  Orchestrates admission flow:
  - request hashing
  - idempotency decision
  - PHI commit
  - receipt update and API response mapping
- [`com.patienteventswriteplatform.patient.service.IdempotencyService`](src/main/java/com/patienteventswriteplatform/patient/service/IdempotencyService.java)  
  Redis key: `idempotency:{event_id}` with 4h TTL.  
  Exposes:
  - `admitOrGet(...)`
  - `markCommitted(...)`
  - `markRejected(...)`
  - `markFailed(...)`
  - `get(...)`
- [`com.patienteventswriteplatform.patient.service.RequestHashService`](src/main/java/com/patienteventswriteplatform/patient/service/RequestHashService.java)  
  Canonical payload hashing via SHA-256.
- [`com.patienteventswriteplatform.patient.service.ReadService`](src/main/java/com/patienteventswriteplatform/patient/service/ReadService.java)  
  Read/query behavior for De-ID and PHI endpoints.
- [`com.patienteventswriteplatform.patient.service.PhiCommitService`](src/main/java/com/patienteventswriteplatform/patient/service/PhiCommitService.java)  
  Transactional PHI writes and version handling.

### `repo/` (Persistence layer)

- [`com.patienteventswriteplatform.patient.repo.PhiRepository`](src/main/java/com/patienteventswriteplatform/patient/repo/PhiRepository.java)  
  JDBC access for:
  - `phi_patient_head`

## Key Data/State Concepts

- **Idempotency receipt state** lives in Redis and maps to [`Phase`](src/main/java/com/patienteventswriteplatform/patient/domain/Phase.java).
- **PHI authoritative tables** are managed via Liquibase in [docs/schemas/liquibase.yaml](../docs/schemas/liquibase.yaml).
- **CDC and projection** are handled outside this module by Flink and infra components under [infra/](../infra/).
